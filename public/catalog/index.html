Language and technology detection

UCE uses project manifests, declared dependencies, imports, configuration files, source extensions, content signatures, and repository structure to identify primary, secondary, and mixed languages together with the technologies used by a project.

Language coverage includes JavaScript, TypeScript, Python, Java, Kotlin, Go, Rust, PHP, Ruby, Elixir, Erlang, Dart, Swift, C, C++, C#, Scala, R, Julia, Lua, Solidity, shell languages, data languages, infrastructure languages, and additional source and template formats.

Technology coverage includes web, mobile, desktop, backend, API, CLI, library, monorepo, AI and machine learning, data science, blockchain, game development, infrastructure, serverless, container, database, testing, and deployment ecosystems.

Compatibility intelligence

The catalog documents UCE knowledge for code and architecture, dependencies, runtimes, operating systems, builds, testing, performance, accessibility, APIs, databases, environments, deployment, licenses, documentation, maintainability, and repository health.

Browser and security checks

Browser entries explain target-version compatibility and fallback recommendations. Security entries explain deterministic static checks, severity, confidence, review requirements, and false-positive limitations. Static findings are review signals and are not proof of runtime behavior or an exploitable vulnerability.

Transparent detection evidence

Each catalog entry presents its category, supported evidence, knowledge version, recommendation, and analysis limitation. Actual scan results depend on the evidence available in the analyzed project.
