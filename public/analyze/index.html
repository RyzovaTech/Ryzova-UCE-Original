Analyze a Project with UCE

UCE is an open-source, local-first software compatibility checker for Git repositories and project archives. Use this page to inspect a project before development, debugging, or deployment.

How UCE analyzes your project

Upload a ZIP archive or provide a public GitHub repository. UCE analyzes the project in your browser and detects its structure, programming languages, frameworks, runtimes, package managers, dependencies, lockfiles, build tools, and configuration. Deterministic compatibility rules then identify common runtime, dependency, configuration, and structure risks.

What the compatibility report contains

The generated report summarizes detected technology choices and compatibility findings with severity, impact, and practical next steps. UCE is designed for developers, indie hackers, software teams, and open-source maintainers who want a clear engineering baseline before a project becomes blocked by a setup or version mismatch.

Local-first and open source

ZIP project archives remain in your browser during local analysis. UCE is open source and built around transparent, deterministic checks rather than AI-generated guesses. The project source and contribution information are available publicly on GitHub.
