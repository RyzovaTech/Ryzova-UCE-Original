# Contributing to UCE

Thank you for your interest in contributing to UCE — Universal Compatibility Engine.

## How to Contribute

1. Fork the repository.
2. Create a new branch for your change.
3. Make your changes.
4. Test your changes locally.
5. Commit your changes with a clear commit message.
6. Push your branch.
7. Open a Pull Request.

## Development

UCE is an open-source project focused on software compatibility analysis.

Before submitting a Pull Request:

- Make sure the project builds successfully.
- Make sure existing functionality is not unnecessarily broken.
- Keep changes focused and understandable.
- Do not commit secrets, API keys, passwords, or private credentials.

## Pull Requests

Please provide:

- A clear description of the change.
- The reason for the change.
- Any relevant screenshots or test results.
- Information about possible breaking changes.

## Issues

Before opening an issue, please check whether a similar issue already exists.

For bugs, include:

- What happened.
- What you expected to happen.
- Steps to reproduce the problem.
- Relevant error messages.
- Environment information when useful.
