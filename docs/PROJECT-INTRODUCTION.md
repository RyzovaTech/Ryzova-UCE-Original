## Short description

Ryzova UCE (Universal Compatibility Engine) is an open-source developer tool from Ryzova for
analyzing software projects and identifying compatibility issues before deployment.

## Project overview

Ryzova UCE analyzes ZIP project archives and public GitHub repositories using deterministic,
browser-based checks. It detects project structure, languages, frameworks, runtimes, package
managers, dependencies, lockfiles, build tools, configuration, and compatibility risks. The result
is an engineering report that organizes findings by severity, impact, and recommended next steps.

ZIP archives are analyzed locally in the browser. Public repositories are downloaded only after a
user explicitly provides a repository URL, then analyzed in-browser. Ryzova UCE is open source
under the Apache License 2.0.

## Technical feature summary

- ZIP archive and public GitHub repository analysis
- Language, framework, runtime, package-manager, and build-tool detection
- Dependency, configuration, structure, and runtime compatibility checks
- Deterministic findings rather than AI-generated analysis
- Scored engineering reports with severity, impact, and recommended next steps
- Local browser analysis for ZIP project archives
